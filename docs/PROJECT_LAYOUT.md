# 项目目录与整理记录

| 路径 | 用途 |
| --- | --- |
| install.exe | 克隆后双击运行的 Windows 安装入口 |
| installer/ | 安装界面源码和 Windows manifest |
| src/ | 当前桌宠、动画和三个官网聊天窗口代码 |
| assets/v3–v7/ | 当前运行资源，沿用原路径；旧图片也保留 |
| assets/source/ | 本地参考图、原始图集和生成记录，Git 忽略 |
| assets/source/references/ | 原来放在根目录的三个本地参考 JPG |
| scripts/assets/ | 图片和图集维护工具 |
| scripts/build/ | 打包入口与发布文件白名单 |
| scripts/checks/ | 测试、调试和预览工具 |
| scripts/windows/ | 自动安装、程序激活和快捷方式工具 |
| tests/ | 不请求真实模型的单元测试 |
| docs/ | 当前安装、使用和开发说明 |
| docs/prompts/ | 公开的图像生成提示词 |
| docs/archive/ | ANIMATION-V2、V3、V4 历史记录，以当前使用说明为准 |
| .cache/ | 下载、依赖工具、安装日志、暂存版与旧程序备份，Git 忽略 |
| artifacts/ | 本地预览、截图与隔离测试资料，Git 忽略 |
| dist/ | 本地可运行程序和用户数据，Git 忽略 |

本次整理删除了 15 个过期的非图片文件：旧的 `更新动画.cmd`，`.cache/` 中的临时补丁脚本、旧调试文本和日志，以及上次速度调整用的临时源码副本。旧动画说明归档，公开提示词移入 docs/prompts，脚本按用途分组。

整理前记录了 1,953 个原有图片文件；全部保留，三个根目录参考 JPG 仅移动位置。素材、缓存、旧程序备份和用户数据保留。应用的图片引用路径未改变。

原始素材、参考图和运行帧的内容均未修改。自动回归检查刷新了 artifacts 中的四张本地测试截图，其文件仍保留；后续安装测试使用独立副本和测试快捷方式目录。
