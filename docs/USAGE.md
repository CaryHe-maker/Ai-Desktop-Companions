# 使用说明

## 安装和启动

安装 Git，在普通可写目录克隆项目，双击根目录 `install.exe`，阅读说明并同意后等待安装完成；桌面会生成三个角色快捷方式。安装器会自动补齐兼容 Node.js 和锁定依赖，详见 [Windows 安装说明](INSTALL.md)。开发者也可安装 Node.js 24 LTS 后手动运行 `npm ci`、`npm start`。网络需能访问 Node.js、npm、Electron 下载地址及所使用的服务。

开发运行同时启动三个角色。便携版支持 `Deskbot.exe --pet=gpt`、`--pet=claude`、`--pet=deepseek` 单独召唤；托盘菜单也可召唤、归位和退出。

## 对话

- **GPT、Claude、DeepSeek** 都使用官网网页的输入、上传、模型选择、历史和搜索功能。分别打开 `chatgpt.com`、`claude.ai/new`、`chat.deepseek.com`。
- 首次在对应官方页面登录自己的账号。顶栏提供返回、新对话、刷新、完整网页、文字大小、外部浏览器及设置。验证需手动完成，项目不绕过验证或额度限制。
- 附件格式、大小、模型及功能以官网为准。应用已移除本地 API 调用、密钥输入和旧的本地会话管理。

## 窗口和动作

桌面角色置顶，透明区域穿透点击；聊天窗口不置顶，可最小化或被其他应用覆盖。点击角色再次显示聊天。右键菜单提供走路、左右看看、鞠躬、问好、伸懒腰、休息和小屋出场。

设置中可调整尺寸、闲逛和减少动态效果。GPT 使用朝侧面换脚的完整角色帧；DeepSeek 使用完整角色换脚帧；Claude 保留原行走素材。三者的走路、左右看看、轻轻鞠躬、摆手问好在上一版基础上加速 50%：三个日常动作从 3.98 秒缩短至约 2.65 秒，一次行走从 9.84 秒缩短至 6.56 秒，桌面移动速度同步提高 50%。伸懒腰仍为 3.98 秒，其他动作保持原速度。每个角色的开场在原动画上新增了 10 帧。

自动动作结束后，角色会先安静休息 12–36 秒，再随机选择下一个动作（原间隔 t = 12 秒，现为 t 到 3t）。三位角色分别抽选时间和动作，不连续重复同一自动动作；关闭闲逛后不会自动选择走路。鼠标停在角色上、拖动、思考或睡眠时不会触发自动动作。手动选择动作仍立即响应，动画本身的播放速度不受此随机间隔影响。

## 本地数据

| 运行方式 | 数据目录 |
| --- | --- |
| `npm start` | 项目内 `data/` |
| 便携程序 | exe 同目录 `data/` |
| 自动测试 | `artifacts/test-data/`，与真实账户隔离 |

三家官网的登录 Cookie 和浏览器资料分别保存于数据目录的 `Partitions/`，本地设置保存为 JSON。聊天由官网管理。旧版 API 密钥和本地聊天文件升级时保留，但新版不会读取或调用，也不会自动上传到官网。不要分享整个数据目录或旧版备份。

重置状态前先退出程序并自行备份或重命名数据目录；官网云端聊天不会因删除本地数据而删除。

## 更新和打包

1. 保存改动、更新代码后运行 `npm ci`、`npm test`。
2. `npm run package` 生成暂存版。
3. 从托盘退出旧程序，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/windows/activate-build.ps1`。
4. 启动 `dist/Deskbot-win32-x64/Deskbot.exe`；可执行 `scripts/windows/install-shortcuts.ps1` 建立快捷方式。

普通用户可直接双击根目录 `install.exe` 完成首次安装或更新，安装器会保留旧数据并创建三个桌面快捷方式。旧的 `更新动画.cmd` 已移除。上面的手动流程用于开发；已激活的暂存版不能重复使用，再次更新需重新打包。完整步骤见 [安装说明](INSTALL.md)。

## 常见问题

- **npm.ps1 被拦截**：改用 `npm.cmd ci`、`npm.cmd start`。
- **安装失败**：检查 Node.js 版本和网络；不要公开带令牌的代理地址、npm 配置或环境变量。
- **官网登录/样式异常**：刷新、切换完整网页或使用外部浏览器；应用与外部浏览器登录状态独立。
- **官网无法连接**：刷新、检查网络或使用“在浏览器中打开”；账号权限及额度由官网管理，无需配置 API Key。
- **角色不可见**：检查系统托盘，使用召唤、全部归位；检查尺寸设置。
- **未知发布者**：目前未进行商业代码签名，请自行从可信源码构建。
- **旧动作/聊天仍置顶**：退出整个托盘程序，而非只关闭聊天，再启动更新后的 exe。
