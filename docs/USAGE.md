# 使用说明

## 安装和启动

安装 Git 和 Node.js 24 LTS，在普通可写目录克隆项目，运行 `npm ci`、`npm start`。使用锁定依赖，不要复制他人的 node_modules、缓存或数据。网络需能访问 npm、Electron 下载地址及所使用的服务。

开发运行同时启动三个角色。便携版支持 `Deskbot.exe --pet=gpt`、`--pet=claude`、`--pet=deepseek` 单独召唤；托盘菜单也可召唤、归位和退出。

## 对话

- **GPT / Claude**：使用官网网页的输入、上传、模型选择和历史。顶栏提供返回、新对话、刷新、完整网页、文字大小、外部浏览器及设置。首次在官方页面登录；验证需手动完成，项目不绕过验证或额度限制。
- **DeepSeek**：在设置填写自己的 API Key。当前代码请求 `https://api.deepseek.com/chat/completions`，模型标识为 `deepseek-flash`。如果服务商调整此标识，可修改 `src/providers.cjs` 并重新测试；项目不保证远端模型永远可用。
- DeepSeek 会话面板支持继续、新建、搜索、重命名和删除。“新对话”不清除旧会话。
- DeepSeek 图片入口支持 PNG/JPEG/WebP，每次最多 4 张，单张上限 12 MB；发送前缩小到最长边 2048 像素。发送后才上传，模型能力以实际接口响应为准。
- DeepSeek 联网选项将查询发送到 Bing，使用最多 6 条结果摘要，**不是完整网页阅读**。官网网页使用各自原生搜索功能。

## 窗口和动作

桌面角色置顶，透明区域穿透点击；聊天窗口不置顶，可最小化或被其他应用覆盖。点击角色再次显示聊天。右键菜单提供走路、左右看看、鞠躬、问好、伸懒腰、休息和小屋出场。

设置中可调整尺寸、闲逛和减少动态效果。行走使用完整双步循环；左右脚交替支撑，起步与停步速度共同驱动脚步和窗口移动。

## 本地数据

| 运行方式 | 数据目录 |
| --- | --- |
| `npm start` | 项目内 `data/` |
| 便携程序 | exe 同目录 `data/` |
| 自动测试 | `artifacts/test-data/`，与真实账户隔离 |

API Key 经 Electron safeStorage 使用系统机制加密；聊天记录及图片保存为本地 JSON，未额外加密。GPT/Claude 会话位于数据目录的 `Partitions/`。不要分享整个数据目录，即使凭据已经加密。旧版备份也可能含敏感数据。

重置状态前先退出程序并自行备份或重命名数据目录；官网云端聊天不会因删除本地数据而删除。

## 更新和打包

1. 保存改动、更新代码后运行 `npm ci`、`npm test`。
2. `npm run package` 生成暂存版。
3. 从托盘退出旧程序，运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/activate-build.ps1`。
4. 启动 `dist/Deskbot-win32-x64/Deskbot.exe`；可执行 `scripts/install-shortcuts.ps1` 建立快捷方式。

`更新动画.cmd` 是已打包版本的激活入口，首次使用前也需先打包。已激活的暂存版不能重复使用；再次更新需重新打包。

## 常见问题

- **npm.ps1 被拦截**：改用 `npm.cmd ci`、`npm.cmd start`。
- **安装失败**：检查 Node.js 版本和网络；不要公开带令牌的代理地址、npm 配置或环境变量。
- **官网登录/样式异常**：刷新、切换完整网页或使用外部浏览器；应用与外部浏览器登录状态独立。
- **API 错误**：检查自己的 Key、额度、模型和权限。无 Key 时程序会提示，不会使用作者账户。
- **角色不可见**：检查系统托盘，使用召唤、全部归位；检查尺寸设置。
- **未知发布者**：目前未进行商业代码签名，请自行从可信源码构建。
- **旧动作/聊天仍置顶**：退出整个托盘程序，而非只关闭聊天，再启动更新后的 exe。
